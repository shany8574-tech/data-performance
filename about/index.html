About Me

데이터의 성능을 극대화하는 데이터 엔지니어

소개

안녕하세요! 데이터 성능 최적화를 전문으로 하는 엔지니어입니다. SQL 쿼리 튜닝, 데이터베이스 설계, Python 기반 데이터 분석을 통해 데이터가 더 빠르고 효율적으로 흐르도록 만드는 일을 합니다.

복잡한 쿼리의 실행 계획을 분석하고, 인덱스 전략을 설계하며, 대용량 데이터 파이프라인의 병목을 찾아 해결하는 것이 주요 업무입니다. Python과 다양한 시각화 라이브러리를 활용하여 데이터에서 인사이트를 추출하고 명확하게 전달하는 것을 좋아합니다.

핵심 역량

SQL Performance Tuning

Oracle, PostgreSQL, MySQL의 쿼리 최적화, 실행 계획 분석, 힌트 활용

Python Data Analysis

Pandas, NumPy, Matplotlib, Seaborn을 활용한 데이터 분석 및 시각화

Database Architecture

인덱스 설계, 파티셔닝, 샤딩, 반정규화 전략

ETL & Data Pipeline

대용량 데이터 처리 파이프라인 설계 및 최적화

# Data Performance Lab

SQL 쿼리 튜닝, 데이터베이스 최적화, Python 데이터 분석에 대한 기술 블로그이자 포트폴리오 사이트입니다.

## 📂 Structure

```
data-performance/
├── _config.yml          # Jekyll 설정
├── _layouts/            # 레이아웃 템플릿
├── _includes/           # 재사용 컴포넌트
├── _posts/              # 블로그 포스트
├── _portfolio/          # 포트폴리오 프로젝트
├── assets/
│   ├── css/main.css     # 스타일시트
│   └── js/main.js       # JavaScript
├── blog/                # 블로그 목록 페이지

├── about/               # About 페이지

```

## 📝 Blog Topics

- **SQL Query Tuning** - 실행 계획 분석, 인덱스 전략, 쿼리 최적화
- **Python Data Analysis** - Pandas, Matplotlib, Seaborn 활용 분석 & 시각화
- **Database Architecture** - 인덱싱, 파티셔닝, 설계 전략
- **ETL & Pipeline** - 대용량 데이터 처리 파이프라인 최적화
- **Performance Monitoring** - DB 모니터링 자동화 및 대시보드

## 🛠 Tech Stack

- **Static Site Generator**: Jekyll
- **Hosting**: GitHub Pages
- **Charts**: Chart.js
- **Styling**: Custom CSS (Dark/Light Theme)
- **Analysis Tools**: Python, Pandas, Matplotlib

## 🚀 Local Development

```bash
# Ruby & Bundler 필요
gem install bundler
bundle install
bundle exec jekyll serve
```

`http://localhost:4000/data-performance` 에서 확인 가능합니다.
